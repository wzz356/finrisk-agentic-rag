## 结果口径

80条来自赛事官方风险测试话术，20条为此前已核定的非风险对照。98/100采用固定分母，1条漏报、1条执行失败均计错。

该最终成绩包含对5条执行失败请求各进行一次人工重试，其中4条生成了正确结果；原轮为94%。具体记录保存在汇报的方法附录和逐条输出中。本次发布没有修改Agent重试策略，也没有新增模型调用。

本批含前期开发材料，非独立盲测。准确率仅衡量风险二分类初筛，不衡量完整合规审查、风险标签、案例排名或整改建议质量；99条有效输出中96条仍带需复核提示。

本目录为既有实测记录的原样交付，不包含密钥或模型权重。核验文件和原始报告中的Windows路径是历史运行定位信息，读者不需要具有相同目录即可查看测试原文和结果。重现付费实验还需兼容的知识快照、运行版本和独立预算，不应因打开本目录而自动调用API。
