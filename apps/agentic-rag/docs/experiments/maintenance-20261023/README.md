## 结果及适用范围

| 轮次 | 固定分母 | 实际结果 | 解释边界 |
|---|---:|---|---|
| DeepSeek百份实验 | 100 | 80实验协议批准；3待核；1不新增；16其他未通过 | 同一模型在独立上下文扮演两个角色；并非100份人工准确率 |

Codex的4份不新增包括3份重复文书和1份非处罚行政许可。已知重复文书在Proposer阶段读取正确旧文书全文后判断；仅替换Reviewer的B090仍漏掉重复。B059引用覆盖失败在一次格式修正后仍未恢复，按上限停止。

百份实验记录412次物理请求，其中404次有已知用量、8次未知；已知2,013,557 tokens。高峰费率保守估值6.686524元，加未知预留0.627872元，合计占用7.314396元，低于30元上限。这是估值及预留，不是供应商账单。

Codex实际采用原生子任务，指定 `gpt-6.1-sol`、`low`、最多3个角色并发；共30个提议/审核角色任务、87次证据工具调用。没有逐任务token计量，不能换算精确API费用。原CLI指定模型探针失败，随后使用支持该配置的原生执行方式；没有将CLI探针当成成功推理。

两轮分别观察到约14.4分钟和23.6分钟的执行窗口，包含不同协调及校验环节；样本与执行器不同，不能据此比较模型速度。

## 可支持的答辩结论

- 在完整旧库只读基线上，可以批量生成增量提案、保留失败并构建独立影子视图。
- Reviewer在部分案例中能够纠正标签要件和对象错配，也会漏检或提出不一致意见。
- 完整旧文书回读可以帮助识别重复；确定性身份匹配和分页覆盖仍需完善。
- 结构与引用校验能够阻断部分不满足协议的输出，审核通过仍不能代替语义正确或人工批准。

12份Codex材料是针对已知问题选取的诊断集，不是未见测试集；模型和执行层同时改变，不能作为纯模型A/B或总体提升结论。本次没有执行真实旧记录更正、停用、撤销处理，也不能声称已清除全部矛盾或过时案例。历史处罚不能仅因日期较早而删除。法规库未纳入本轮实验。


## 证据与公开处理

公开副本保留全部选定样本、原文、来源URL、业务结果、错误与限制；移除个人本机路径、账户配额、内部任务标识、供应商原始运行日志及密钥相关配置。公开处罚材料及其姓名、机构来自所列监管来源，模型提案是待核实验输出，不代表新增法律判断。

`provenance.json`记录原始文件SHA与公开转换；`checksums.json`记录本目录文件SHA。脱敏后的文件哈希与原始文件可能不同；原始文本哈希保持。最终验证文件和旧资产保护摘要是实验时的主机检查记录，公开核验脚本不具备访问私有原件、重新认证模型调用或替代人工语义审核的能力。

影子manifest保留原始资产标识与哈希作为历史引用，其本机路径已经移除，不能直接用作安装清单。公开包没有重复上传整份旧库，也没有切换已有V2 Release。
