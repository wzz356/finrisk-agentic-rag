# Competition500 自建效果测试集

当前唯一效果集位于 `data/eval/competition500_v1/`。旧效果集及入口已清理；GitHub仅发布本目录的新数据及公开结果。

## 数据与划分

| 数据 | 数量 | 用途 |
|---|---:|---|
| 真实处罚案例 | 500 | 固定候选池，每案来自不同文书 |
| 开发Query | 400 | 训练本地候选模型、示例校准和参数调整 |
| 开发核对子集 | 100 | validation.jsonl，为400开发Query的前100条，不是额外独立留出集 |
| 测试Query | 200 | 与开发源文书分离，冻结参考后报告效果 |
| 开发相关性Query | 400 | 每条覆盖500候选 |
| 测试相关性Query | 200 | 每条覆盖500候选 |

开发Query种子来自300份文书，测试来自另外200份。场景固定ST1–ST6，风险标签固定27类；包含风险表达、禁止与纠错、正常流程和信息不足。长文本按实际长度单独统计。

## 标注来源

版本为`competition500-codex-reviewed-v2-20261019`。Query原由Pi/DeepSeek依据真实处罚事实改写、原参考由Qwen辅助生成。本次由Codex自己逐条阅读全部600条Query、全部500个案例，对33个摘录不完整条目回查来源全文；没有调用DeepSeek、Qwen或其他模型进行标注复核。新的参考是Codex直接复核结果，不属于人类专家金标。真实API仅用于运行项目推理和效果测试。

相关性采用 `direct-source-review-mechanisms-v3`：0无共同动作，1仅宽泛类目或载体，2同一具体动作，3至少两个相同具体动作。完整矩阵从逐条复核的行为目录确定性展开：开发400×500、测试200×500，不将30万对称为独立人工逐对判断。2/3级提供双方原文、来源文书和SHA；只有标签或培训、电销等背景相同不能强相关。无正例Query保留并单列，不强行将生成种子作为正例。

357条Query修正了状态、标签或场景，72个案例修正标签或摘录。`reference/query_reviews.jsonl`、`reference/case_reviews.jsonl`保留全量逐条记录，`reference/review_changes.json`保留修改前后和理由。原始输入文本保持稳定，没有根据系统预测修改答案。

## 文件边界

- `cases.jsonl`：真实案例、原文事实及来源指纹。
- `model_inputs.jsonl`、`development.jsonl`、`validation.jsonl`、`test.jsonl`：系统输入。
- `reference/generation_plan.jsonl`：生成过程和种子分组，仅用于制作审计。
- `reference/labels.jsonl`：场景、三态与标签答案，仅由评分器读取。
- `reference/qrels_development.jsonl`、`reference/qrels_test.jsonl`：相关性等级和双方证据。
- `manifest.json`：版本、数量、来源及输入/答案指纹。

索引不包含评测Query和答案。本地模型及示例检索仅训练于400开发Query；最终200条不参与训练和默认配置选择。

## 指标口径

风险部分报告二分类准确率、Precision/Recall/F1、三态准确率、标签Micro/Macro-F1、逐标签支持数和六场景准确率。超时和失败保留在分母。

检索报告命中率@1/@5、Recall@3/@5/@10/@20、MRR@20、NDCG@10。强相关为等级≥2；没有强相关案例的Query单列计数。命中率指至少找到一个相关案例，Recall指相关案例集合覆盖率，分别展示。

结果适用于本项目500案例闭集，不外推为9,639份文书全库或官方隐藏测试成绩。

本轮参考已校正，与旧银标指标不能直接作同口径涨跌比较。开发核对包含在本地候选模型拟合数据中，效果报告以200条test为准；如果展示旧模型，须用新参考重新评分其冻结预测。已确认违规不因金额、责任或其他机制待核而清空；第三方反面教材、纠错和被否决方案不直接当作当前违规。
