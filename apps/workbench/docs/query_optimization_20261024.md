# Query 优化与 200 条回归（2026-10-24）

本轮从 `3293e16dab333e9f08e3ff57a42b7f5c572b301d` 建立新基线。原 500 个候选案例、200 条测试输入、参考标签和相关性判断均保持原样。最终候选通过事前固定的发布门槛：标签质量提高，状态准确率和风险召回持平，二分类准确率下降 1/200。完整数值见 `reports/query_optimization_20261024/comparison.json`。

## 数据与训练

新增 72 条训练样本，覆盖 24 个场景组和 27 个标签；每组包含明确风险、合规/否定和缺必要事实三种情况。另留 8 个不同场景组、24 条验证样本，其中 3 条长于 1,600 字符。样本由 Codex 编写并复核，保留原文 SHA-256、Unicode 码点区间、标签理由和具体缺失事实。它们是工程标注，不是人工专家金标。

本地字符 n-gram 候选模型用原开发集 400 条加新训练集 72 条训练，没有微调 DeepSeek，也没有把新增验证集或原 200 条测试集放入训练。提示示例优先选语义相关的不同状态对照，降低两个相似风险示例共同诱导肯定判断的倾向。模型文件新增实际训练版本和维度/数值检查。

审计确认训练与验证场景组不重叠；新训练集与新验证、原开发集、原测试输入均无规范化后的文本完全重复。最大字符三元组 Jaccard 分别为 0.127273、0.069767、0.042254。这只是文本重叠检查，不能证明完全没有语义重叠。

## 逻辑修正

- 已否决且未执行的方案只约束自己的作用域；其他段落已查实的独立事实继续审查，不能被整篇判为反面示例。
- 明确的“以上为错误示范、实际展业不得照此表述”向同一作用域的前文解释引用立场；独立已实施事实保留自己的语境。
- “先展示错误例句，随后要求新人按这句讲，不得改成非保证”属于实际采纳指令，不能被“不得”这个词直接放行；“禁止要求新人照讲”仍按否定处理。
- 同句“收益不保证”不能盖过客户明确拒绝后换号码继续营销的独立行为，补充相关语义变体。
- 提示词要求逐标签核对行为、对象和必要条件。收益承诺不自动证明收益率被编造；欺骗监管不自动等于欺骗投保人；主管账号、会务公司、相同录音背景均不能单独证明其他关联风险。
- 非自适应路径的补标签规则同步收窄：保留明确编造收益率和无资质实际销售等事实支持，减少依靠共同出现的词语附加关联标签。原来将收益承诺、历史收益延伸或手工测算一律标成“虚构收益率”的单元测试改为区分这些事实。

原文、句子 ID、证据回读和知识版本锁继续约束结果。新增语义测试覆盖这些边界；没有更换知识库或文档向量。

提升主要来自标签判断，不是风险二分类准确率。二分类多错 1 条，恰好位于允许下降 0.5 个百分点的边界；不能描述为所有指标均提升。精简逐条预测与两版源码哈希随报告保留。全量 322 项 Python 测试、18 项直接 Node 测试、Ruff、87 个源文件的 Mypy 通过。

两端均使用当前 `finrisk_full_20261024` 知识库中的同一 500 案例闭池、Qwen 原生 1024 维向量、DeepSeek 重排、adaptive 风险模式、自动场景分类和真实 Pi API。每版完整跑 200 条风险审查与 200 条检索；使用当前基线，避免把 10 月 19 日旧环境的数字直接当成本次对照。

事先固定的发布门槛：状态准确率、风险二分类准确率、标签 micro-F1 至少一项提升 1 个百分点，且其中任一项下降不超过 0.5 个百分点；风险召回率、场景准确率、Hit@5 和 NDCG@10 各下降不超过 1 个百分点；查询错误和未完成模型目标均为零。未通过则不上传、不部署。

本评估是重复使用旧参考答案的工程回归，参考答案并非专家金标，不能声称为全新独立测试或赛事成绩。每版各跑一次真实模型，包含模型非确定性；小样本提升不能解释为已证明统计显著。检索指标仅针对 500 案例闭池，不代表 10,000 份以上知识库的完整召回质量。

复现入口为 `scripts/evaluate_query_development.py`、`scripts/benchmark_competition500.py` 和 `scripts/report_query_promotion.py`。正式报告保留各版 200 条精简预测、源码哈希、数据审计、门槛检查和校验结果；API 原始轨迹与运行时依赖副本留在本机输出目录，不进入 Git。
