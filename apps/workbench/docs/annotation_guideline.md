# Query与类案相关性标注规范

当前版本为`competition500_v1`。真实DeepSeek API生成Query，独立Qwen调用标注六场景、三态和27标签；Qwen逐候选标注案例相关性。参考为模型辅助银标；标注员不读取被测系统预测。

## 六类场景

| 场景 | 定义 |
|---|---|
| ST1 | 海报、短信、朋友圈及社交平台短文案 |
| ST2 | 直播、短视频及口播 |
| ST3 | 产品介绍、详情页及说明内容 |
| ST4 | 产品说明会、客户活动及讲师材料 |
| ST5 | 内部培训、电销、回访及异议处理 |
| ST6 | 处罚文书及后台业务事实 |

按载体分类，载体本身不构成违规。系统测试使用自动场景识别，不提供参考场景。

## 风险状态与标签

- `risk`：当前材料支持的违规陈述、执行要求或已发生事实。
- `no_clear_risk`：正常流程、否定违规、禁止性培训等，没有成立的风险机制。
- `insufficient_information`：合同、资质、事实或数据不明，保留候选标签与缺失事实。
- 标签限27类词表，允许多标签，不按父子或近义关系自动补齐。
- “其他”用于已成立但不能归入其余26类的行为，不代替未知。
- 培训、回访、电销、说明会载体标签须与实际风险相结合。

证据须为Query连续原文，解释另存。独立机制分别判断，一项事实不足不覆盖另一项已成立风险。反面示例和禁止性话术结合上下文判断，历史案例不作为当前事实。

## 相关性0–3分

每条Query明确标注全部500候选，比较具体行为机制。正常或禁止性Query仍可与其讨论的处罚行为相关。

| 分数 | 标准 |
|---|---|
| 0 | 行为无关；仅同属保险、销售或管理不够 |
| 1 | 宽泛类型相同，缺少具体行为或条件对应 |
| 2 | 具体行为机制一致，有双方原文依据 |
| 3 | 行为和关键条件高度一致 |

2/3分同时保存Query和案例事实的连续引文。源片段编号还原为逐字原文；无法回引则重新请求，不将未标注项当作0。强相关阈值2；Hit@K与集合Recall@K分别统计，NDCG使用0–3分。

## 划分和使用

500案例来自500份不同文书。300份构造400开发Query，其余200份构造200测试Query；源文书和文本无交集。开发集可训练轻量模型、提供示例和调参；最终测试不进入训练、示例或默认选择。默认由100条开发风险验证与60条开发相关性验证综合冻结。

早期宽泛相关性草稿隔离到`reference/drafts`，不参与评分。旧效果集已归档停用。Web人工复核另存于`data/processed/reviews/query_reviews.jsonl`，不自动改写冻结参考。
