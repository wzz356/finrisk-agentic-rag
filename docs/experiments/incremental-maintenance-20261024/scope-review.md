# 五份范围排除与一份待核：理由及复核边界

这里的“排除”是模型建议不将材料加入**保险业务检索范围**，不是删除来源文件，也不是判定其过时或与旧库矛盾。“待核”是现有文本不足以决定接纳还是排除。全部建议尚未获人工正式批准。

以下说明来自本轮冻结的处罚公示文本、提议和审核记录；未另行核实官网完整文书或机构业务登记。原始记录保存在[paired-results.json](paired-results.json)。

| 编号与主体 | 原文披露的主要事实 | 模型当时的处理理由 | 事后核读意见 |
|---|---|---|---|

D18展示了Reviewer阻止证据不足的排除建议，但没有证明该材料一定涉及保险业务。审核之后仍存在D14、D20这类证据门槛问题，说明双角色意见一致不能代替独立核验。

对照D19：人保寿险吉林省分公司的“换领许可证超期”被警告并罚款1万元，两个角色都保留了新增候选。它是保险机构的处罚案件，不能因“许可证／换领”字样就排除为行政许可公告。
