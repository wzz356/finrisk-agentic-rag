## Agent 100条初筛

80条官方风险话术+20条补充非风险对照，含前期开发材料。

- 首轮94条正确、1条误判、5条执行失败。
- 对5条失败各人工补发一次最终判定请求，新增4条正确；最终98/100。
- 最终仍有1条误判、1条执行失败，均保留在分母中。
- 99条有效输出中96条带需复核提示。

该结果仅评价是否识别风险，不评价27标签、证据、排名或整改建议的完整正确性；人工补发不等于系统自动恢复。该批非独立盲测，与工作台200条验收分别统计。

来源：[100条初筛报告、原文与逐条生成结果](../apps/agentic-rag/docs/experiments/agent-binary100-20261025/README.md)。

## 知识维护实验

在10,000份旧文参照下完成20份新增材料的开发实验，形成14份建议新增、5份建议排除、1份待核。正式80份未运行，影子候选未更新正式库；D14、D20排除依据仍需复核。

双角色产生42个输出、143次证据操作。结果证明实验流程可回放，不代表Reviewer准确率为100%或已经验证全库自动维护效果。

来源：[20份增量维护实验](../apps/agentic-rag/docs/experiments/incremental-maintenance-20261024/README.md)。
